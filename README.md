# Real-Time Helmet and Triple Riding Violation Detection Using YOLOv8 and ByteTrack for Smart Traffic Surveillance

This project is a smart traffic surveillance system designed to detect two-wheeler safety and traffic violations in real time. It identifies motorcycles and riders from traffic video, detects helmet and no-helmet cases, checks helmet strap compliance, and recognizes triple riding violations.

The system also uses ByteTrack for rider tracking, PaddleOCR for vehicle number plate extraction, and automated PDF challan generation to support faster and more reliable traffic enforcement.
